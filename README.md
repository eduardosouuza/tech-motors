# Tech Motors — Landing Page

Landing page estática e responsiva para a Tech Motors, oficina mecânica em Viamão/RS.

## Estrutura

```text
├── assets/        # Logo e imagens institucionais
├── css/            # Estilos e responsividade
├── js/             # Interações, animações e WhatsApp
└── index.html      # Página principal
```

## Publicação no GitHub Pages

Após enviar este projeto para um repositório GitHub, acesse **Settings → Pages**, selecione **Deploy from a branch**, e escolha a branch `main` com a pasta `/ (root)`.

O site não requer etapa de build: `index.html` é o ponto de entrada.
